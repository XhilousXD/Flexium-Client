## 🎮 About Flexium

<div align="center">

> ### *"Built for players who want full control, without the clutter."*

</div>

**Flexium** is a modern, lightweight, and highly customizable launcher for **Minecraft Java Edition**. Whether you're running a clean vanilla world or juggling five different modpacks, Flexium keeps everything organized, fast, and completely under your control.

<br>
